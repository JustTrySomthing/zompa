# Zompado for Android

Play and chat with friends.<br>
Discover fun and unique games,<br>
and easily make and share your own.

[Download for Android (ARM64)](https://github.com/JustTrySomthing/zompado/releases/latest) · [Browse the game catalog](https://github.com/JustTrySomthing/zompado-games)

## What you can do today

- **Play Drop Four.** Go solo against the computer or take turns with a friend on the same phone.
- **Discover and install games.** Open **Games → Get Games** to browse the official catalog and install games in the app.
- **Invite and message friends in the Android preview.** Create a Chatmail profile, share an invite link or QR code, and exchange encrypted one-to-one text messages. [Get the signed preview](https://github.com/JustTrySomthing/zompado/actions/runs/44613350401#artifacts).

The public APK includes a local chat preview. For online messaging, download the `zompado-signed-android` ZIP from the preview build and extract the APK. The preview supports ARM64 Android devices with 4 KB memory pages.

## Game Builder coming soon

Chat with AI to turn your idea into a Zompado game you can play and share. The Game Builder will be available as an optional download.
